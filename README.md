# GETSTARVIS

Site officiel du média GETSTARVIS — « Le monde en mouvement ».

## Développement

    npm install
    npm run dev
    npm run lint
    npm run build
    npm run preview

## Structure

- src/data/media.js centralise les catégories et les contenus d’exemple.
- src/components/media/ contient les éléments partagés de navigation et d’interface.
- src/pages/media/ contient les pages d’accueil, rubriques, articles, recherche et STARVERIFY.
- public/brand/ contient le symbole et le lockup officiels fournis par la rédaction.
- public/robots.txt et public/sitemap.xml fournissent les premiers fichiers SEO.

Les contenus éditoriaux présents sont des exemples fictifs, signalés dans l’interface. La météo reste un emplacement prévu pour un futur fournisseur de données et n’affiche pas de localisation supposée.
